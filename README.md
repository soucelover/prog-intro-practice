## Домашнее задание 3. Реверс

Модификации
 * *Base*
    * Исходный код тестов:
        [ReverseTest.java](java/reverse/ReverseTest.java),
        [ReverseTester.java](java/reverse/ReverseTester.java)
    * Откомпилированные тесты: [ReverseTest.jar](artifacts/ReverseTest.jar)
        * Аргументы командной строки: модификации
 * *Memory*
    * Программа должна сначала считывать все данные в память,
      и только потом обрабатывать их.
    * Пусть _M_ – объём памяти, необходимый для сохранения ввода
      в двумерном массиве `int` минимального размера.
      Ваша программа должна использовать не более 4_M_ + 1024 байт памяти
    * Накладные расходы на запуск вашей программы JVM не учитываются
 * *41*
    * Во вводе и выводе используются шестнадцатеричные числа
    * Рассмотрим входные данные как (не полностью определенную) матрицу,
      вместо каждого числа выведите сумму чисел в его столбце и строке
    * Решение должно соответствовать ограничениям *Memory*
    * Класс должен иметь имя `Reverse41`
 * *42*
    * Во вводе и выводе используются шестнадцатеричные числа
    * Рассмотрим входные данные как (не полностью определенную) матрицу,
      вместо каждого числа выведите сумму абсолютных значений чисел в его столбце и строке
    * Решение должно соответствовать ограничениям *Memory*
    * Класс должен иметь имя `Reverse42`
 * *3839*
    * Во вводе и выводе используются шестнадцатеричные числа
    * Рассмотрим входные данные как (не полностью определенную) матрицу,
      вместо каждого числа выведите сумму абсолютных значений чисел в прямоугольнике верхний левый угол матрицы — текущее число
    * Решение должно соответствовать ограничениям *Memory*
    * Класс должен иметь имя `Reverse3839`
